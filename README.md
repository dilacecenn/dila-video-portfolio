# Dila Çeçen — Art & Motion Portfolio

A static English portfolio website prepared for GitHub Pages. It features original paintings and four experimental video studies.

## Publish on GitHub Pages

1. Open https://github.com/new and sign in as `dilacecenn`.
2. Create a **Public** repository named `dila-video-portfolio`.
3. Upload **the contents of this extracted folder** (`index.html`, `styles.css`, `assets`, `.nojekyll`) to the repository's **root** and commit to `main`.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Once publishing completes, the expected website address is:

   https://dilacecenn.github.io/dila-video-portfolio/

This is an expected URL pattern, **not a verified published site**.

## Contents

- `index.html` — the page
- `styles.css` — responsive styling
- `assets/images/` — real artwork images from Dila Çeçen's uploaded PDF plus video thumbnail images
- `assets/videos/` — four MP4 files already created for this portfolio

All video work is described as demonstration edits rather than independent professional client work. Source artwork belongs to Dila Çeçen. The static site uses no backend. Google Fonts requires internet; fallback system fonts are provided.

Make sure Dila Çeçen agrees to publicly publish the paintings, video demonstrations and displayed contact email. GitHub Pages on a public repo will be viewable by anyone.
